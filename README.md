# 💸 Expense Splitter (Python)

A simple Python project that calculates shared expenses among multiple people based on rent, food, and electricity usage.

---

## ✨ Features

* Split rent among roommates
* Add food/snacking expenses
* Calculate electricity bill using units × charge per unit
* Automatically divide total cost equally
* Beginner-friendly CLI project

---

## 🧮 Logic Overview

The total expense is calculated as:

* Rent + Food + Electricity Bill
* Electricity Bill = Units × Charge per Unit
* Final split = Total ÷ Number of Persons

---

## 📌 Example

```
Enter the rent amount: 5000  
Enter food cost: 2000  
Enter electricity units: 100  
Enter charge per unit: 5  
Enter number of persons: 4  

Total Bill: 7500  
Each person should pay: 1875
```
